## 一、基础敌人

### 1. 竹影刀客 `bamboo_blade`

- **出现**：竹雾村、山道、废弃驿站 → 地图：山门主廊、旧城街巷、崖底/水岸过渡、绝顶点缀  
- **外形**：破旧短衫、斗笠、单刀；巡逻缓慢，发现玩家后压低接近  
- **动作**
  - 横向快斩：速度快、范围短  
  - 蓄力下劈：刀身短暂红光，威力高  
  - 后撤闪身：连续受击时后撤  
  - 两刀连击：中后期横斩接反手斩  
- **窗口**：收刀硬直是主要反击点  
- **定位**：教学格挡距离、翻滚时机与普攻节奏  

### 2. 屋脊弩手 `rooftop_bow`

- **出现**：竹雾村屋顶、悬崖栈道、无相殿城墙 → 地图：闸口高台、灯市屋脊、矿口、栈道、殿墙  
- **外形**：瘦长、蓑衣、长弩，占高台或远平台  
- **动作**：单发（红线瞄准）、三连速射、穿透重箭、后跳换位  
- **窗口**：箭可劈落或翻滚穿过  
- **定位**：逼迫移动，避免站桩换血  

### 3. 墨羽鸦 `ink_crow`

- **出现**：竹林上空、断崖、黑松湖 → 地图：屋脊、矿井、雾径、栈道、水殿上空  
- **外形**：乌鸦 + 墨雾 + 符纸；翅缘散墨点  
- **动作**：俯冲啄击、墨羽散射、群体盘旋、濒死墨雾  
- **窗口**：血低速快；上挑 / 跳斩 / 弩箭可坠地硬直  
- **定位**：打断跳跃与攀爬  

### 4. 墨腹蛛 `ink_spider`

- **出现**：墨骨窟、剑冢牢下层、秘密通道 → 地图：暗渠、矿灯岔口、通风巷、矿底  
- **外形**：湿润墨块 + 白骨关节；可贴墙顶移动  
- **动作**：墙顶突袭、吐丝束缚、毒墨地面、幼蛛孵化  
- **窗口**：腹暗红光＝吐丝；打腹部额外伤害（需翻身/跃下时机）  
- **定位**：地下伏击与弱点瞄准  

### 5. 铁甲盾卫 `iron_shield`

- **出现**：剑冢牢、无相殿外围、机关门前 → 地图：山门闸口、戏台/城东、矿口/熔炉、龙柱、问心长阶  
- **外形**：残破重甲、方铁盾、短刀  
- **动作**：格挡、盾击、冲撞、反手斩  
- **窗口**：绕后 / 诱撞墙 / 重击破盾；破盾后狂暴（快攻低防）  
- **定位**：惩罚正面硬砍的门卫  

### 6. 提灯术士 `lantern_mage`

- **出现**：悬寺、地下祭坛、黑松祠堂 → 地图：商会阁楼、钟楼精英、雾径/温室、崖侧佛龛、宴厅  
- **外形**：宽袍、符纸遮脸、红光旧灯笼  
- **动作**：地面符阵、墨火弹、召唤墨影、灯灭隐身  
- **窗口**：施法不可移动；碎灯笼打断并长失衡  
- **定位**：普通法术压力；能力奖励战改由独立精英“掌灯使”承担  

### 7. 噬墨兽 `ink_beast`

- **出现**：黑松森林、墨骨深处、污染村落 → 地图：矿工歇所、苔径/雾桥、盲道、水下廊  
- **外形**：狼獒墨团四足兽，奔跑拖墨迹  
- **动作**：连续扑咬、低姿冲锋、墨雾咆哮、残血狂暴  
- **窗口**：扑空撞墙眩晕  
- **定位**：高攻近战，常与远程组合  

### 8. 链狱卒 `chain_jailer`

- **出现**：剑冢牢、刑台、垂直升降井 → 地图：运轨/升降井、轨道岔道、矿底、泄洪闸  
- **外形**：瘦高、断链、钩头长链  
- **动作**：横扫、低扫腿、锁钩抓取、悬空拦截  
- **窗口**：链端红光＝抓取；伸直瞬间可劈开并失衡  
- **定位**：竖井与牢房特色  

### 9. 墨鳞游魂 `ink_eel`

- **出现**：黑松湖水下、沉水行宫回廊  
- **外形**：细长鱼骨与墨带组成，转向前鳞光变亮  
- **动作**：环游盯防、鳞光突刺、尾墨减速带  
- **窗口**：突刺亮光后锁定方向；撞墙回旋时可反击  
- **定位**：水中层追击单位，替代墨羽鸦的空中/坠地逻辑  

### 10. 沉甲水卒 `drowned_guard`

- **出现**：泄洪闸底、沉水行宫水下长廊  
- **外形**：青苔锁链重甲卫兵，只沿水底缓慢行走  
- **动作**：沉盾推进、水柱上冲、锚链回收  
- **窗口**：水柱有气泡预警；锚链落空时背部气囊暴露  
- **定位**：水底空间锚点，与墨鳞游魂组成上下双层压力

## 二、精英敌人

### 11. 掌灯使 `lantern_adept`

- **出现**：旧钟楼、孢囊温室、倒影宴厅  
- **外形**：三层铜环灯笼与可独立移动的悬符灯  
- **动作**：三灯符阵、追魂墨火、移灯换位、熄灯阶段  
- **窗口**：移灯结束与最后一灯落下后的长施法硬直；朱红灯芯是真灯  
- **定位**：能力守门精英；与普通提灯术士使用不同层级和参数  

### 12. 赤枪校尉 `scarlet_captain`

- **出现**：竹雾关隘、悬寺演武、无相前庭 → 地图：守门校场、试剑峰  
- **外形**：黑甲，枪缨与腰带朱红；长枪完整招式  
- **动作**：三段枪术、冲锋贯穿、对空挑杀、枪尾震地  
- **窗口**：看枪尖决定跳/撤/滚；完整枪术后收枪硬直  
- **定位**：小型 Boss 级精英；试剑峰发踏云  

### 13. 无面剑侍 `faceless_sword`

- **出现**：无相殿内、隐藏剑室 → 地图：望月石台、祭坛前廊、终局前廊  
- **外形**：近似主角黑衣、无面、细长双刃剑；模仿玩家招式  
- **动作**：模仿普攻、墨影翻滚、对峙架势、残影突刺  
- **窗口**：假动作骗招架，打侧后  
- **定位**：后期战斗理解检验  

### 14. 湖中墨姬 `lake_maiden`

- **出现**：黑松湖、水下遗迹、月下祭坛 → 地图：月下祭坛（水下）  
- **外形**：长发女子上半身，下半身融水墨；平时仅发与灯影  
- **动作**：水袖横扫、水镜幻身、墨水漩涡、潜水换位  
- **窗口**：攻击前本体露红簪；破分身回灵力不伤本体  
- **定位**：行宫水域精英；分身承担杂兵压力，发放水镜信物

## 三、区 Boss

### 15. 剑冢狱主 `tomb_warden`

- **所在**：剑冢牢最深处 → 地图：剑冢牢底  
- **外形**：废兵器 + 锁链 + 残甲；中央封印巨断剑  
- **阶段**
  1. 锁链与断剑横扫  
  2. 扯断锁链，吸附兵器成多臂剑阵  
- **机制**：攻击改变场地武器位置；可引导劈断牢门与脆弱地面；朱红封印为弱点  
- **奖励**：震地击 · 赤铁印  

### 16. 黑松魇兽 `pine_nightmare`

- **所在**：黑松湖尽头月下枯林 → 地图：月下枯林  
- **外形**：巨大鹿狼妖兽，枯树角，实体/墨雾切换  
- **阶段**
  1. 扑击、角撞、踏地  
  2. 墨雾形态：幻影与多向冲锋  
- **机制**：仅实体可正常承伤；水面倒影判冲锋方向；破角缩短招式范围  
- **奖励**：幽林印  

### 17. 无相殿主 `formless_lord`

- **所在**：无相殿最高层 → 地图：无相殿顶  
- **外形**：白袍、宣纸面、双刃剑；战斗中渐被墨侵  
- **阶段**
  1. 剑术：格挡、突刺、二段连斩  
  2. 化境：钩索追身、震地墨波、踏云二段追斩  
  3. 无相：闭息毒雾与水行镜面交替覆盖场地  
- **定位**：逐项复测钩索、震地击、闭息诀、踏云二段跳和水行符  
- **奖励**：归途传送权限

## 四、关键遭遇规则

- 旧钟楼：W1 刀客 ×2 + 弩手 ×1；W2 掌灯使 ×1。先清跟班，再学习真假灯。  
- 熔炉工坊：W1 墨腹蛛 ×2；W2 盾卫 ×1 + 墨腹蛛 ×1。先处理洞顶警戒，再破盾。  
- 孢囊温室：W1 噬墨兽 ×2；W2 掌灯使 ×1 + 噬墨兽 ×1。毒孢在第二波开启。  
- 试剑峰：W1 弩手 ×1 + 墨羽鸦 ×2；W2 赤枪校尉 ×1。避免三种反跳跃压力同时出现。  
- 倒影宴厅：W1 盾卫 ×2；W2 掌灯使 ×1。先验证绕后，再进入镜面符阵。  
- 水下长廊：西半墨鳞游魂 ×2；东半沉甲水卒 ×1 + 墨鳞游魂 ×1，不封锁回气通道。  
- 月下祭坛：湖中墨姬单体精英，分身由技能生成，不追加空中跟班。  
- 三处区 Boss：均为单体阶段战，复杂度来自场地与阶段变化，不追加杂兵。  

地图房间中的 `ENCOUNTER PLAN` 同步展示波次、数量、触发、站位、刷新规则与难度预算。
