# 墨境行者 · 新手演武场敌人战斗与动作设计

> 状态：演武场首版实现基线  
> 适用范围：新手试玩 / 敌人演示场，不替代世界地图的遭遇部署文档  
> 世界图鉴来源：`app/map/enemies.ts`、`docs/enemies.md`  
> 视觉来源：`public/assets/enemies/sprites/idle/` 与桥魇运行图 `public/assets/enemy.webp`

## 一、目标与边界

新手演武场承担三个目的：让玩家选择并单独观察敌人、验证敌人的攻击与反制窗口、为后续逐帧动画和骨骼动画提供统一动作蓝本。

演武场共有 **18 名敌人、50 种攻击**：

| 分类 | 数量 | 敌人 | 每名攻击数 | 分类攻击总数 |
|---|---:|---|---:|---:|
| 普通敌人 | 10 | 竹影刀客、屋脊弩手、墨羽鸦、墨腹蛛、铁甲盾卫、提灯术士、噬墨兽、链狱卒、墨鳞游魂、沉甲水卒 | 2 | 20 |
| 精英怪 | 5 | 桥魇、掌灯使、赤枪校尉、无面剑侍、湖中墨姬 | 3 | 15 |
| Boss | 3 | 剑冢狱主、黑松魇兽、无相殿主 | 5 | 15 |
| **总计** | **18** | 世界图鉴 17 名 + 演武场专属桥魇 | — | **50** |

桥魇是原新手试玩中的“守桥墨灵”，本次正式定位为精英怪，但暂不计入世界地图 17 名图鉴和部署数量。建议演武场数据 id 使用 `bridge_nightmare`，显示名统一为“桥魇”。

普通敌人在完整世界观文档中可能记有多种候选动作；演武场与首版实战统一收敛为 **一个普通攻击技能（可包含连击）和一个重击技能**。后撤、格挡、巡逻、换位、悬浮、狂暴增速和阶段转换属于移动、反应或状态，不计作新的攻击手段。

## 二、概率与选招契约

### 2.1 固定权重

| 分类 | 招式组成 | 基础权重 | 语义 |
|---|---|---|---|
| 普通敌人 | 普通攻击 / 重击 | 75 / 25 | 普通攻击常见，重击低频 |
| 精英怪 | 轻击 A / 轻击 B / 重击 C | 42 / 42 / 16 | 两种轻击常见，一种重击低频 |
| Boss | 轻击 A / 轻击 B / 轻击 C / 重击 A / 重击 B | 25 / 25 / 14 / 25 / 11 | 两种常见轻击、一种次常见轻击、一种常见重击、一种低频重击 |

每组权重总和必须为 100。权重表示招式在满足距离、阶段和冷却条件后的基础抽取倾向，不代表固定循环顺序。

### 2.2 合格池与防重复

1. AI 先按距离、玩家高度、场上召唤物、阶段和冷却筛选合格招式，再在合格池内按权重重新归一化抽取。
2. 基础敌人重击的单招冷却为 2.9–4.1 秒；触发后必须完整进入收招，不能立刻再次蓄力。
3. 精英重击在开战 4 秒后解锁，基础冷却 7 秒。
4. Boss 常见重击基础冷却 5.5 秒；低频重击基础冷却 11 秒，且同一场战斗开始后的前 7 秒不出现。
5. 精英和 Boss 禁止同一招连续出现三次；Boss 禁止两次重击相邻。
6. 条件招式不满足时不得强放。例如无面剑侍的镜返不在玩家完全停止攻击的长时间段连续尝试。
7. 阶段转换不造成伤害、不消耗招式权重，也不能取消玩家已经成功制造的敌人失衡。
8. 多段普通攻击仍算一招：一次选招、一次前摇、一组连续命中判定、一次收招和一个共享冷却。

### 2.3 演武场基准

- 玩家生命基准沿用现有试玩值 360。
- 轻击强调可读性和稳定压力，单次完整命中通常造成 24–52 伤害。
- 基础敌人重击完整命中通常造成 46–58 伤害，必须提供至少 0.85 秒预警。
- 精英重击完整命中通常造成 64–76 伤害。
- Boss 常见重击完整命中通常造成 76–84 伤害；低频重击完整命中上限约 96，避免无预警秒杀。
- 所有伤害只在“生效 / active”阶段结算；预备、前摇、跟随和收招阶段不得残留隐形伤害判定。
- 玩家在有效翻滚无敌帧内不受伤。飞行道具、锁钩和可劈散墨火应能被玩家攻击销毁或弹开。

## 三、通用行动状态机

| 状态 | 目的 | 可进入下一状态 |
|---|---|---|
| `observe` 观察 | 面向玩家，读取距离、高度和最近动作 | `reposition`、`telegraph` |
| `reposition` 调位 | 接近、后撤、绕行、悬浮、潜水或回到锚点 | `observe`、`telegraph` |
| `telegraph` 前摇 | 播放姿势和预警；方向可在指定锁定帧前修正 | `active`、被打断后进入 `stagger` |
| `active` 生效 | 开启命中盒、飞行道具或场地判定 | `followThrough` |
| `followThrough` 跟随 | 保留惯性、位移和视觉拖尾，不新增未声明判定 | `recovery` |
| `recovery` 收招 | 明确反击窗口，AI 不得选招 | `observe` |
| `stagger` 失衡 | 撞墙、弱点被破或法术被打断后的额外输出窗 | `observe`、阶段转换 |

轻击使用灰白、敌人区域色或微弱朱红点作为局部提示；重击必须同时具备全身蓄力姿势、朱红危险信号和地面 / 路径预警中的至少两项。常见重击前摇不得短于 0.85 秒，低频重击不得短于 0.95 秒。

## 四、普通敌人：10 名、20 招

以下内容同时覆盖每名敌人的 **基础移动动画** 与两项 **技能动作动画**。所有“分镜”都是同一固定侧视镜头中的动作节拍，不允许真正切镜；时间必须和运行配置的前摇、active、跟随、收招一一对应。

每条提示词都默认附加同一组生产约束：**24fps，以该敌人的游戏内透明立绘为唯一角色参考，2D 水墨横版侧视，角色面朝右；背景为完全均匀的纯绿色 #00FF00，无地面、无阴影、无渐变、无纹理、无环境物体；固定镜头、固定角色尺寸、固定脚底或悬浮基线；服装、武器、脸部与轮廓比例全程一致，全身完整入镜；无文字、无 UI、无其他角色；禁止缩放、浮空、脚底漂移、换脸、肢体增生和武器变形。攻击和移动素材均采用原地 root-motion 动画，实际横向/纵向位移由游戏逻辑驱动，避免双重位移。首尾姿势必须可衔接待机或循环；只保留贴身武器拖影和少量墨点，大范围路径预警、地面判定、弹道与命中特效单独制作。**

### 1. 竹影刀客 `bamboo_blade`

**行动模式：** 缓慢巡逻；发现玩家后压低身形接近至约 1.5 身位；横斩后原地收刀。连续受击时后撤半个身位属于移动反应，不新增攻击。

| 招式 | 类型 / 权重 | 时间轴 | 伤害 | 视觉特效 | 玩家对策 |
|---|---|---|---:|---|---|
| 竹影横斩 | 普通攻击 · 常见 / 75 | 前摇 0.30s；命中 0.12s；跟随 0.12s；收招 0.52s | 28 | 灰白半月刀弧与竹叶状墨点 | 后撤或向身后翻滚；收刀时反击 |
| 赤刃下劈 | 重击 · 低频 / 25 | 前摇 0.90s；命中 0.18s；跟随 0.18s；收招 0.90s | 48 | 刀背朱红蓄满，脚前短红线与纵向重墨刀痕 | 红线锁定后翻滚穿身；拔刀硬直时反击 |

**动画生成提示词（移动 / 受击 / 技能）**

- **基础移动「竹影潜步」｜1.00s / 24 帧 / 无缝循环**
  - **分镜与时间：** 分镜1 `0.00–0.12s` 斗笠压低、前脚试探；分镜2 `0.12–0.50s` 右脚落地、左脚跟进，刀鞘轻摆；分镜3 `0.50–0.88s` 左脚落地、右脚回收，肩部反向补偿；分镜4 `0.88–1.00s` 回到与首帧完全一致的潜行姿势。
  - **移动描述：** 运行时追击速度为舞台宽度 `7%/s`；生成素材只表现原地交替步态和身体前倾，不产生画面内真实位移。
  - **完整提示词：** 竹影刀客压低斗笠缓慢潜步，双膝保持低位，脚掌先着地再压实，斗笠、衣摆和刀鞘随步伐轻微反向摆动，目光始终锁住前方，动作克制、警惕、有竹林刺客感，首尾帧严格闭环。 背景为完全均匀的纯绿色 #00FF00，无地面、无阴影、无渐变、无纹理、无环境物体。
  - **专项约束：** 脚底不得滑动或离开基线；单刀始终在鞘侧，不自动挥刀；左右步幅一致，不改变人物身高和宽度。
- **受击反应「刀客受创」｜0.60s / 约15帧**
  - **分镜与时间：** 分镜1 `0.00–0.08s` 胸肩出现命中停顿；分镜2 `0.08–0.22s` 上身向后拧转、斗笠偏斜；分镜3 `0.22–0.40s` 后脚踏稳、持刀手护住胸前；分镜4 `0.40–0.60s` 重整重心回到警戒待机。
  - **移动描述：** 受击方向默认来自角色正前方；素材仅表现后仰和踏步，实际击退建议由游戏逻辑向后 `2–3%` 舞台宽度处理。
  - **完整提示词：** 竹影刀客胸肩被正面攻击命中，身体短暂停帧后向后扭转，斗笠被震歪、衣摆甩起，后脚快速撑住地面，单刀不脱手，短暂疼痛后重新压低重心进入警戒。 背景为完全均匀的纯绿色 #00FF00，无地面、无阴影、无渐变、无纹理、无环境物体。
  - **专项约束：** 不倒地、不转身背对镜头、不掉落武器；脚底最终回到原基线；受击闪光和血墨由独立特效层生成。
- **普通攻击「竹影横斩」｜1.06s / 约26帧**
  - **分镜与时间：** 分镜1 `0.00–0.30s` 压低斗笠、藏刀蓄势；分镜2 `0.30–0.42s` 拔刀水平横斩，命中中心在 `0.36s`；分镜3 `0.42–0.54s` 刀势掠过并甩出少量墨点；分镜4 `0.54–1.06s` 刀尖下沉、稳定收刀回待机。
  - **移动描述：** active 阶段运行时向前突进，速度 `18%/s`、位移预算 `3.5%` 舞台宽度；动画根节点固定，只表现前脚蹬地、腰胯前送和衣摆后拖。
  - **完整提示词：** 竹影刀客肩腰下沉，右手将单刀藏在身后，短促停顿后以前脚为轴完成一次干净快速的拔刀横斩，刀锋经过身体正前方时速度最大，形成贴身灰白半月刀光和竹叶状墨点，随后甩墨归刀。 背景为完全均匀的纯绿色 #00FF00，无地面、无阴影、无渐变、无纹理、无环境物体。
  - **专项约束：** 刀弧仅贴近身体，不绘制远距离判定；前脚可蹬地但根节点不移动；收刀尾帧必须与待机姿势兼容。
- **重击「赤刃下劈」｜2.16s / 约52帧**
  - **分镜与时间：** 分镜1 `0.00–0.45s` 双手举刀、后腿承重；分镜2 `0.45–0.90s` 刀背朱红逐段点亮并保持蓄力；分镜3 `0.90–1.08s` 猛然下劈，命中中心在 `0.99s`；分镜4 `1.08–1.26s` 刀刃嵌地、身体随惯性下压；分镜5 `1.26–2.16s` 费力拔刀，暴露长硬直后回待机。
  - **移动描述：** active 阶段运行时向前突进，速度 `14%/s`、位移预算 `4.5%`；动画只表现蹬步和上身前压，不产生真实前移或跳起。
  - **完整提示词：** 竹影刀客双手缓慢将单刀举过头顶，身体下沉，刀背朱红从刀镡亮至刀尖；锁定后收腹转肩完成高力量纵向重劈，刀锋在前下方急停并留下短促重墨刀痕，随后像刀刃嵌地般停顿，费力拔起再恢复警戒。 背景为完全均匀的纯绿色 #00FF00，无地面、无阴影、无渐变、无纹理、无环境物体。
  - **专项约束：** 双脚始终接触基线；禁止角色缩小、浮空或随刀势穿出画面；地面红线、裂痕和命中震波独立制作。

### 2. 屋脊弩手 `rooftop_bow`

**行动模式：** 锚定远端或高台，保持约 7–10 身位；玩家进入 4 身位内时后跳换位；视线清晰后射击，装填阶段不能移动。

| 招式 | 类型 / 权重 | 时间轴 | 伤害 | 视觉特效 | 玩家对策 |
|---|---|---|---:|---|---|
| 朱线穿弩 | 普通攻击 · 常见 / 75 | 前摇 0.65s；箭矢飞行 0.65s；跟随 0.10s；收招 0.85s | 30 | 细朱红瞄准线、黑色弩矢与灰白破风尾迹 | 侧移、翻滚或劈落弩箭；装填时贴身输出 |
| 贯梁重矢 | 重击 · 低频 / 25 | 前摇 1.10s；箭矢飞行 0.90s；跟随 0.16s；收招 1.20s | 50 | 贯穿路径的粗红线、重矢墨痕与木屑冲击 | 路径锁定后跳离或翻滚穿矢；长装填时压制 |

## 七、动作制作模板

每个攻击动画必须按以下五段制作和审查。即使首版仅使用静态造型加 CSS，也要让五段在位移、缩放、旋转和停顿上可辨。

### 7.0 攻击特效起点（实现基线）

攻击特效不得统一从地面生成。每招必须声明一个语义发射点，由演武场换算成舞台坐标；面向左侧时，敌人自身的发射点和特效贴图一并镜像。锁定目标类招式在进入前摇时记录玩家位置，生效阶段不再追踪玩家，保证预警位置与实际特效一致。

| 发射点 | 坐标基准 | 当前适用招式示例 |
|---|---|---|
| `weapon` 武器端 | 敌人脚底向上 58% 身高、朝目标方向前移 22% 体宽 | 竹影横斩、朱线穿弩、赤钩与无相剑式 |
| `hand` 手部 | 敌人脚底向上 56% 身高、朝目标方向前移 18% 体宽 | 桥魇爪击、灯火术、水袖与魇爪 |
| `head` 头 / 角 | 敌人脚底向上 72% 身高、朝目标方向前移 12% 体宽 | 墨鸦俯冲、墨鳗头槌、枯角横冲 |
| `mouth` 口部 | 敌人脚底向上 60% 身高、朝目标方向前移 20% 体宽 | 墨兽吐息、桥魇影噬 |
| `body` 身体中心 | 敌人脚底向上 48% 身高，水平居中 | 盾冲、换位、残兵飞射、墨尾回林 |
| `ground-self` 自身脚下 | 敌人脚底地面、朝目标方向前移 12% 体宽 | 桥潮、裂地狱门、踏月震林、殿心震墨 |
| `ground-target` 目标脚下 | 前摇锁定的玩家横坐标与地面交点 | 灯符、溺卫泉涌、漩涡葬月 |
| `target-body` 目标身位 | 前摇锁定的玩家横坐标、玩家脚底向上 50% 身高 | 镜兵对刺 |
| `target-air` 目标上空 | 前摇锁定的玩家横坐标、玩家脚底向上 120% 身高 | 墨蛛坠袭、断剑坠刑 |
| `arena-center` 场地中心 | 舞台水平 50%、地面向上 4% 舞台高度 | 三灯阵、万刃归冢、百魇夜奔、无相覆境 |

地面发射点只用于地裂、震波、法阵、落点和场地覆盖类招式；挥砍、喷吐、飞射、扑击等特效必须从对应的武器或身体部位开始。

| 段落 | 英文状态 | 制作要求 | 命中盒 |
|---|---|---|---|
| 预备 | `anticipation` | 从待机进入攻击意图；改变重心、视线或武器朝向，先让玩家看懂“谁要出招” | 关闭 |
| 前摇 | `windup` | 积蓄力量并显示方向 / 地面预警；在文档指定锁定时刻后不得继续追踪玩家 | 关闭 |
| 生效 | `active` | 武器、身体、飞行物或场地效果越过目标区域；视觉峰值必须与伤害帧同步 | 开启，仅限声明时段 |
| 跟随 | `followThrough` | 表达冲量、惯性和挥空，不得偷偷增加新方向的未声明判定 | 默认关闭；多段招式按文档明确开启 |
| 收招 | `recovery` | 回到可行动姿态；形成玩家稳定可利用的反击窗口 | 关闭 |

制作关键帧建议命名为：`{enemyId}__{attackId}__anticipation`、`__windup`、`__active`、`__follow`、`__recovery`。后续若拆逐帧图，帧序号追加在状态后，如 `__active__03`。

### 7.1 轻重攻击动作语言

- 普通 / 轻击：预备幅度小，重心变化集中在武器侧；前摇通常 0.24–0.70 秒；效果峰值不遮挡敌人弱点。
- 常见重击：至少一个完整大幅蓄力姿势，前摇至少 0.85 秒；生效前必须出现朱红路径或地面范围。
- 低频重击：允许使用全身变形、场地覆盖或镜头轻震，但前摇至少 0.95 秒，且必须提前给出可到达的安全位置。
- 飞行敌人和水栖敌人需在攻击前改变飞行 / 游动轨迹，不能只依赖 UI “危”字。
- 镜返、格挡和弱点破坏必须有独立姿势，不能仅通过颜色滤镜表达。

## 八、VFX 母版、CSS 分层与命名

### 8.1 一敌一母版

演武场首版采用 **每名敌人一个透明攻击特效母版**，共 18 张：

```text
public/assets/enemies/effects/combat/{enemyId}.webp
```

可返修色键源图统一放在：

```text
local-art-source/editable/enemies/effects/source/{enemyId}-chroma.png
```

母版是该敌人的共同笔触与色彩素材，不为每招重复生成图片。不同招式由 CSS 动作类改变位置、朝向、缩放、裁切、重复层数、透明度和播放节奏。建议 DOM 仅保留一个 `.enemy-effect` 节点，并以伪元素复制同一母版：

```text
.enemy-effect.fx--{enemyId}
.enemy-effect.attack--{attackId}
.enemy-effect.kind--light | .kind--heavy
.enemy-effect.phase--windup | .phase--active | .phase--recovery
```

建议使用以下 CSS 变量驱动，而不是为 40 招新增 40 张图：

```text
--fx-x              特效相对角色的横向锚点
--fx-y              特效相对角色的纵向锚点
--fx-scale-x        水平覆盖与朝向
--fx-scale-y        垂直覆盖
--fx-rotate         斩击、弹道或冲击角度
--fx-duration       生效动画时长
--fx-opacity        主层透明度
--fx-trail-opacity  跟随层透明度
--fx-impact-scale   命中层扩张比例
--fx-clip           不同招式的裁切形状
--fx-filter         仅做轻微亮度 / 对比度调整，不用来改变敌人身份色
```

同一敌人的不同招式至少改变上述属性中的三项，并改变时间曲线或伪元素数量，确保玩家在不看招式名时也能区分。重击不能只是把轻击等比放大；必须额外加入地面预警、分波节奏、重复层或反向运动之一。

### 8.2 概念分层

以下“层”是 CSS / 伪元素的职责，不要求拆成额外图片文件：

| 层 | CSS 建议 | 职责 |
|---|---|---|
| 预警层 | `.fx-tell` 或容器 `::before` | 红线、符环、倒影、安全区、锁定点；在伤害前完整出现 |
| 主体层 | `.enemy-effect` | 使用 `{enemyId}.png` 呈现敌人专属笔触、刀弧、墨潮或法术形状 |
| 拖尾层 | `.enemy-effect::before` | 复制母版，降低透明度并延迟 40–100ms，表达速度和方向 |
| 命中层 | `.enemy-effect::after` | 在伤害帧快速放大 / 闪白，表达接触点；不能提前出现 |
| 地面层 | `.fx-ground` 或容器背景 | 裂纹、蛛丝、尾墨、水纹和安全通道；与角色特效分开定位 |

### 8.3 身份色

- 竹影 / 兵刃类：灰白锋光 + 极少朱红命中点。
- 提灯系：铜橙 + 朱红符印 + 黑色纸灰。
- 水系：蓝灰 / 银白 + 红簪或红色锁定点。
- 幽林兽系：绿黑 + 月银边缘 + 暗红弱点。
- 剑冢系：铁灰 / 赭红 + 朱红封印。
- 无相系：黑白反相 + 极细朱红危险线。

身份色必须服从“灰黑水墨主体、少量朱红只用于危险与弱点”的项目视觉语言，不允许用大面积高饱和霓虹覆盖角色。

## 九、VFX 与动作验收规则

### 9.1 文件验收

1. `public/assets/enemies/effects/combat/` 下存在 18 张与敌人 id 一一对应的 PNG。
2. 文件必须为 RGBA 并包含真实透明区域；不得把黑色、白色或棋盘格背景烘焙进图片。
3. 母版不得包含角色本体、场景、文字、UI、“危”字或血条。
4. 主特效四周至少保留约 5% 安全边距，避免缩放和翻转时被裁断。
5. 默认方向与角色默认朝向一致；角色翻面时，特效和命中盒必须同时翻面。
6. 母版应保持清晰硬边和自然墨边，不得出现色键残边、白色方框或明显 JPEG 噪声。

### 9.2 动作可读性验收

1. 关闭招式名称 UI 后，观察者仍能从前摇和路径判断攻击方向。
2. 同一精英的两种轻击能在 0.3 秒内辨别；重击能在伤害前至少 0.85 秒辨别。
3. 同一 Boss 的五招至少在方向、覆盖范围、节奏或安全区中的两项不同。
4. 前摇预警先于伤害；主体视觉峰值与命中盒开启误差不超过 50ms。
5. 收招期间不残留伤害；表现上仍存在的墨雾若无判定，应快速降透明度，避免误导。
6. 飞行道具与可破坏法术在被劈散的同一帧关闭伤害盒并播放命中层。
7. 轻击、重击、受击和死亡状态切换不得互相遗留 CSS 类或计时器。
8. 翻滚穿过攻击后不发生延迟补伤；多段攻击只在文档声明的每段命中窗结算。
9. 撞墙、破灯、坠地、破角、破盾和封印暴露必须进入可观察的失衡动作，而不是仅停止 AI。
10. 在常见桌面宽度和移动端缩放下，特效不遮住玩家、敌人和安全区三者中的两者以上。

### 9.3 概率验收

在关闭距离和阶段限制的测试模式中，每名精英抽样至少 2,000 次、每名 Boss 抽样至少 5,000 次：

- 精英每招实测比例与 42% / 42% / 16% 的偏差不超过 3 个百分点。
- Boss 每招实测比例与 25% / 25% / 14% / 25% / 11% 的偏差不超过 3 个百分点。
- 实战模式另行确认重击不相邻、阶段锁正确、冷却生效且没有不可达安全区。

## 十、实现与后续动画交接

- 演武场 UI 的分类文案使用“普通敌人 / 精英怪 / Boss”；底层仍可沿用 `basic / elite / boss`。
- 选中敌人后必须同时重置其生命、位置、阶段、招式历史、冷却、飞行道具、召唤物和场地残留。
- 试玩页当前桥魇的角色位置与攻击距离为固定值；接入 18 名敌人时应使用独立敌人坐标和本文状态机，不能只替换图片与名称。
- 本文时间轴是动作团队的首版基线。逐帧或骨骼动画落地后可在不改变攻击数量和概率契约的前提下微调前摇、命中和收招，但任何缩短重击预警的修改都必须重新做可读性验收。
