# 地图流程与成长链重设计 · v0.6

## 设计目标

- 移除钩索与二段跳后，不再用大跨度位移能力维持旧路线。
- 把成长拆成战斗招式、环境能力、剧情凭证三层。
- 每个区域的核心内容都在离区前完成，不把缺失目标拖到终局才提示。
- 主线保证清晰，能力回溯只承担秘密路线、强化材料和捷径奖励。

## 三层成长系统

| 类别 | 内容 | 用途 |
|---|---|---|
| 战斗招式 | 瞬步、十字斩 | 改变战斗节奏，在专门房间反复验证，不作为普通钥匙滥用 |
| 环境能力 | 震地击、闭息诀、水行符 | 打开脆地、毒雾、水下等具有明确世界语义的路线 |
| 剧情凭证 | 悬灯印、赤铁印、幽林印、水镜信物 | 证明区域核心目标完成，控制区域出口或终局入口 |

## 新主流程

1. **雨蚀山门**：基础教学 → 守门校场 → 学会瞬步 → 雨亭箭廊安全验证 → 离区。
2. **悬灯旧城**：主街调查 → 屋脊/阁楼探索 → 旧钟楼精英 → 学会十字斩并取得悬灯印 → 城东印闸验证 → 离区。
3. **赤铁矿脉**：矿道与升降井 → 熔炉 → 剑冢狱主 → 获得震地击与赤铁印 → 侧井回中层 → 赤铁封门即时验证 → 离区。
4. **孢子幽林**：雾径环廊 → 孢囊温室 → 获得闭息诀 → 毒雾支路与月下枯林 → 获得幽林印 → 开放索桥。
5. **断云天险**：索桥 → 崖底恢复回环 / 悬寺主攀升 → 试剑峰综合复测瞬步与十字斩 → 下山云梯 → 离区。
6. **沉水行宫**：水上主廊 → 倒影宴厅 → 获得水行符 → 泄洪闸 → 水下长廊 → 湖中墨姬 → 获得水镜信物 → 水镜升流进入绝顶。
7. **无明绝顶**：水镜天门 → 五式短验证 → 三印祭坛整备 → 无相殿主完整复测 → 开放归途传送。

## 支路与回溯

- 山门崖下：早期单向落下与回程教学，不设能力门。
- 旧城暗渠：获得震地击后回访，奖励强化材料和主街捷径。
- 废弃矿底：矿区通关后立即可震碎脆地进入，形成第一次短回溯。
- 幽林盲道：取得闭息诀后可选，连接回雾径环廊并提供稀有收集物。
- 断云崖底：失足恢复路线，不把坠落只处理为死亡惩罚。
- 绝顶回城口：通关后开放，服务全图收集而不是补救主线遗漏。

## 招式教学节奏

### 瞬步

1. 守门校场：面对枪尖长预警学习穿身和脱离。
2. 雨亭箭廊：低伤箭线进行安全验证。
3. 剑冢狱主 / 黑松魇兽：处理中期链击与实体冲锋。
4. 试剑峰：处理高台火力与赤枪贴身。
5. 无相殿主：识别敌方瞬步残影并反用瞬步抢窗口。

### 十字斩

1. 旧钟楼：对真假灯的双点弱点完成教学。
2. 城东印闸：对盾卫进行破势验证。
3. 剑冢牢底：破坏兵器阵交叉节点。
4. 试剑峰：打断赤枪完整枪术后的架势。
5. 无相殿主：在十字墨斩外侧反击交锋。

## 强制校验规则

- 山门出口要求瞬步。
- 旧城出口要求悬灯印。
- 矿区出口要求赤铁印，并现场验证震地击。
- 幽林出口要求幽林印。
- 绝顶入口要求水镜信物。
- 最终 Boss 房要求瞬步、十字斩、震地击、闭息诀和水行符。

这样即使玩家忽略所有秘密支路，也不会在终局才发现漏掉某个完整区域的核心奖励。
