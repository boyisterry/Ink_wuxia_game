# 场景图五层规范

所有场景图固定按以下顺序由底到顶合成；碰撞数据独立保存，不从位图反推。

1. `00-background-*`：山川、水流远景、岩洞纵深等不可交互背景。
2. `20-background-architecture-*`：背景房屋、桥梁、浮空平台、踏板等构图结构。
3. `30-decoration-*`：竹林、草木、罐子、神龛、灯笼等非地基装饰。
4. `40-effects-*`：水墨、雨雾、地下水、水面反光等透明特效；没有特效时保留透明占位层。
5. `50-foundation-*`：最顶层地基、断崖和可碰撞地面造型。

## 尺寸与连续性

- 单屏工作尺寸为 `1672×941`，导出游戏尺寸为 `3840×2160`。
- 跨屏远景先制作连续画卷，再按精确屏界裁切；不得分别调色。
- 跨屏装饰使用世界坐标透明层，只保存一份，再从同一资产精确裁入相邻屏幕的第 3 层，不得分别绘制两半；例如 S02–S03 使用 `shared/s02-s03-seam-bamboo-world.png`。
- 跨屏建筑同样必须保存为单一透明世界资产，再按世界坐标裁入相邻屏幕的第 2 层，不得作为全局顶层覆盖；例如 J02 使用 `shared/s02-s03-stone-culvert-world.png` 跨越 S02、S03。
- 第 5 层轮廓必须与施工图碰撞线对齐；其它图层不得改变物理可达性。

## 地表与隐藏地下层

- 地表场景与隐藏地下场景分别维护完整的五层文件，不得合成在同一张单屏位图中。
- S04–S07 地表摄影机只加载地表五层；发现柴棚暗板并进入隐藏层后，才切换加载 `region-sketch/underground/` 对应五层。地下路线穿过 U01–U03，在 S07 西侧永久梯井回到地表，爬出后直接看见复活锚点。
- 隐藏层按 S04–S07 四屏连续世界绘制，U01、U02、U03 保持双向步行和连续摄影机；S07 返回梯井只负责隐藏层与地表层之间的垂直切换。
- 地下可活动净空不得低于角色站高加完整跳跃高度，并需预留顶部安全余量；当前施工基准为 `312px` 源尺寸。
- 每个跨层入口必须成对编号：地表端使用 `Hxx-A`，地下安全落脚端使用 `Hxx-B`；两端共享世界 X，并记录开启条件、移动方式、单向性、摄影机切层与回程出口。
- 隐藏入口的地表美术只能给出裂纹、渗水、松动草叶等弱提示，不得直接绘制地下房间；明确的编号、箭头和触发范围只出现在工程/玩法标记层。
- 暗板开启、落石、破墙等会改变碰撞状态的动态演出不得烘焙进静态第 4 层；需输出独立透明帧条，并记录“动画总长、碰撞释放帧、落地恢复时间”。S04 的 H01 资源为 `s04/transition/h01-opening-fx-strip.png`。

## S08 守门校场

- 左侧以 `Y=300` 与 S07 的 C54 齐平衔接，校场东侧再逐步收至 `Y=260` 交给 S09；C58–C63 的台面高度由第 5 层逐段锁定。
- 第 2 层的观战长廊必须带连续后墙、落地立柱和柱础；C64 只描述其可踩檐面，不允许画成无支撑的浮空平台。
- C65/C66 是 Boss 生命周期控制的动态封门：常态美术保持开启，不把关闭门体烘焙进第 2 层。
- 校场中央为精英战净空区；旗、钟架、兵器架和能力石台放在后景或两侧，并在第 3 层保留可见落脚点。
- S07 末端取消重复旗门后，以两面带独立石座的残旗填补低墙天际线；旗帜属于第 3 层，不新增碰撞或门洞。
