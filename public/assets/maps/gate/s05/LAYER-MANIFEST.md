# S05 石狮甬道 · 地上场景五层清单

画布为 `1672 × 941`，对应一区施工图的 S05 单屏；游戏展示另导出 `3840 × 2160`。

1. `layers/00-background-mountains.png`：冷灰雨幕、远山与 S04 山势延续。
2. `layers/20-background-architecture.png`：西侧残门、中门、东侧箭楼，以及两处有实体支撑的高台造型。
3. `layers/30-decoration.png`：石狮残像、碑片、竹丛、雨链和小灯亭。
4. `layers/40-effects.png`：斜雨、低雾、地面积水波纹。
5. `layers/50-foundation.png`：最上层连续实体地基。

## 施工锚点

- S04 → S05：入口地面 `Y=610`，无切镜连续步行。
- S05 → S06：出口地面 `Y=600`，在 `X=1080` 以 10px 缓阶完成高度变化。
- C39：`X=520–790 / Y=475`，双柱落到 `Y=610`。
- C40：`X=1050–1360 / Y=445`，双柱落到 `Y=600`。
- 石狮属于背景装饰，不建立阻挡碰撞；两处平台的落脚范围不放置高装饰。

源素材保存在 `source/`，可通过 `npm run art:s05` 重建所有图层、合成图和 S04–S05 接缝预览。
