# S12 山门驿道 · 地表场景五层清单

画布为 `1672×941`，游戏导出尺寸为 `3840×2160`。

1. `layers/00-background-mountains-city.png`：西侧湿山、东侧旧城墙与悬灯街廓的连续渐变。
2. `layers/20-background-architecture.png`：山门驿棚、布幔车架流送门洞及旧城青砖悬灯廊。
3. `layers/30-decoration.png`：行囊、木箱、车轮、雨披、残旗、湿草及向东增密的悬灯。
4. `layers/40-effects.png`：由西向东略减弱的斜雨、低雾、水纹与克制灯晕。
5. `layers/50-foundation.png`：C95–C99 平缓下降的连续实体地基及 C100 驿棚天然屋面。
